# legacy/

`fos/` is the Freight Operations Simulator (FOS) 0.15.0 exactly as it is on `main`, moved here unchanged when Freight World started (stage 0). It is kept for reference only (for example the Wikimedia Commons photo script and the weather adapter); it is not built or published from this branch.

The live FOS site is still built from `main`. Its fonts were moved to `public/fonts/`, so running FOS from this folder needs `main` instead.
